---
name: research
description: "Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent."
---

Spin up a **background agent** to conduct the research so the primary work can continue while sources are reviewed.

The background agent's responsibilities are:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not secondary write-ups. Every claim is traced to the source that owns it.
2. Write the findings to a single Markdown file and cite the source for each claim.
3. Save the file where the repository already keeps such notes, matching the existing convention. If no convention exists, choose a sensible location and report it.
