# Changelog

## 0.1.0

The first packaged Nexus OpenCode profile establishes the installable project structure and the autonomous programming-team workflow.

- Added `nexus init`, `nexus run`, `nexus doctor`, and `nexus version`.
- Added specialist agents, engineering skills, server plugins, and TUI plugins.
- Added an immutable remote-agent source with SHA-256 integrity verification before installation.
- Added installer, package, plugin, and profile validation tests.
